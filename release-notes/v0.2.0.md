Ymir is a node-based procedural terrain generator for Linux. You build terrain by wiring nodes
together, watch it in a 3D viewport, and export heightmaps for a game engine or a DCC package.

This is the first public release, and Ymir is early but usable. It is in `0.x`: the save format
can still change, and a project saved now may need migrating later.

## What is in it

- **49 nodes**: 17 generators (fBm, billow, ridged, hybrid multifractal, three cellular families,
  gradients, shapes, import, paint), 6 selectors (slope, curvature, aspect, height, occlusion,
  flow), 8 adjustments, 6 filters, and a blend.
- **Erosion**: thermal, hydraulic and stream, each a complete model rather than a fragment.
  Thermal also runs on the GPU, with the CPU path kept as the reference.
- **Coastal shaping** against a world sea level, tapping shore, beach and bluff as selections.
- **Painting and sculpting** with a brush, on the 2D map or the 3D surface.
- **Subgraphs**: collapse a network into one node, save it to a library, drop it into another
  project.
- **A 3D viewport** with Gerstner water, foam and a wet shoreline, and a 2D map view.
- **A node pane** listing every node with what it is doing: what is out of date, and what a build
  is running right now.
- **Exports**: 16-bit PNG, `.r16`, and OpenEXR in metres.
- **A headless CLI**, which renders a built-in sample graph and prints the node reference as
  JSON. Rendering a project of your own from it is not there yet.

## Requirements

Linux, on Wayland or X11, and a Vulkan-capable GPU with working drivers. The viewport runs on
Vulkan through wgpu and the editor will not start without it.

## Install

Download `ymir-gui-linux-x86_64`, make it executable, and run it:

```
chmod +x ymir-gui-linux-x86_64
./ymir-gui-linux-x86_64
```

`SHA256SUMS` accompanies the binaries if you want to verify the download. `ymir-cli-linux-x86_64`
is the headless runner.

Building from source is still supported and is described in the
[install guide](https://liminalfield.github.io/ymir/install/).

## Known limits

- **Linux x86_64 only.** There are no Windows or macOS builds.
- **A preview is not a build.** Erosion is an iterative simulation, so it is resolution-dependent:
  a preview is representative of a build rather than identical to it. The build is the source of
  truth.
- **The save format is not stable yet.** It carries a version and changes ship a migration path,
  but 0.x makes no promise.
- **The headless CLI cannot render your project.** It renders a sample graph, which exercises the
  save and reload path; pointing it at a `.ymir` file is not implemented.
- **There is no tutorial yet.** The reference is complete, with a page per node, and a
  start-to-finish walkthrough is still to be written.

## Documentation

The manual is at [liminalfield.github.io/ymir](https://liminalfield.github.io/ymir/): concepts,
how-to pages, and a reference page for every one of the 49 nodes. The tutorial is a placeholder,
not a walkthrough.
