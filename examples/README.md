# Example terrains

Complete Ymir projects (`.ymir`) kept in version control: worked-on terrains preserved
here, and examples to open and learn from. Open one with **File > Open**.

Each file carries its world settings, node graph, and canvas view, so it opens as a
full, buildable terrain. Because a project references the nodes it was built with, an
example loads correctly only on a build that has those nodes; while the node set is
still changing, expect to re-save an example when the file format or a node it uses
changes.
